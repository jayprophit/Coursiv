## Minute-by-Minute Planning
After sorting your budget, let's see how AI can help with event day planning.

### example 01.03

```markdown
Create a [type] [subject] for a full-day [event description] event, including setup and [additional detail].

(type) = [detailed]
(subject) = [timeline]
(event description) = [corporate celebration]
(additional detail) = [breakdown]
```

#### An effective event planner always prepares for the unexpected. Which prompt would you use to generate the most effective contingency plan for your celebration?
"Create a comprehensive contingency plan for our corporate celebration, addressing potential issues such as technical failures, catering problems, and last-minute cancellations"

As you can see, it is also not about the length of the prompt but about the details and precision.
Although both prompts above have similar word counts, only one is good. This is because of its well-built structure, which will result in a proper response.
