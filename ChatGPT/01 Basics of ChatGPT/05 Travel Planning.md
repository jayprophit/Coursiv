## Become a Travel Agent with ChatGPT
As a travel agent, your main goal is to create personalized and engaging travel plans for your clients.
For this, you need to come up with a variety of travel package ideas for different types of clients.
This includes family vacations, adventure trips, and luxury getaways.

### example 01.01
```markdown
You are a [role] at a travel agency.
[task] [number] travel package ideas for different types of [subject].

(role) = [travel agent]
(task) = [Generate]
(number) = [five]
(subject) = [trips]
```

### example 01.02
```markdown
Create a [type] itinerary for a [trip type] vacation.

(type) = [detailed]
(trip type) = [family]
```

## Answering Questions
While we were creating a travel plan, we received a lot of emails. Let's use ChatGPT to address these client queries efficiently. Clients often have questions about destinations and travel logistics, so let's see how AI can help us respond quickly and accurately.

### example 01.04
```markdown

(who) = [client]
(query) = [travel logistics]
```

### example 01.05
